The queue records accepted requests in timestamp order. It evicts timestamps whose age is at least the window before checking capacity. Rejected requests are not appended, so repeated rejected attempts do not prolong the window. A call can evict n entries: O(n) worst case. Each accepted entry is appended and removed at most once, giving amortized O(1) work per call over the sequence. Callers must preserve nondecreasing time and a positive fixed window. The mutable reference permits queue updates without transferring ownership.
